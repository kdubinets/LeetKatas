# Exercise Manifest

## Initial Batch

| Exercise | Primary skill | Secondary topics |
|---|---|---|
| `balanced_tree_height` | Propagate either a subtree height or an unbalanced failure state | Postorder, early failure |
| `tree_diameter_in_edges` | Return one subtree measure while updating a separate aggregate | Postorder heights, edge count |
| `validate_strict_bst_bounds` | Propagate strict optional ancestor bounds downward | Extreme integer values, duplicates |
| `sum_root_to_leaf_numbers` | Extend a path accumulator before descending | Leaf detection, widened arithmetic |
