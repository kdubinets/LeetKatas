# Exercise Manifest

## Initial Batch

| Exercise | Primary skill | Secondary topics |
|---|---|---|
| `generate_k_combinations` | Restore a shared choice path after each recursive branch | Increasing choices, remaining-capacity pruning |
| `permute_distinct_values` | Mark and unmark a selected input position around recursion | Distinct values, deterministic order |
| `target_sum_combinations` | Recurse with a reusable candidate and stop on sorted overshoot | Positive values, remaining target |
| `word_search_with_restoration` | Restore a temporarily marked grid cell on success and failure paths | Four neighbors, no cell reuse |
