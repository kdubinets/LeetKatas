# Minimum Array Changes to Make Differences Equal

An even-length array `nums` contains values in `[0,k]`. In one change, replace any one entry by any value in that same range. Find the fewest changes that make all mirrored pairs have the same absolute difference: for some integer `X`, `|nums[i]−nums[n−1−i]|=X` for every index. `2 ≤ n ≤ 10^5`, `n` even, and `0 ≤ k ≤ 10^5`. Return the number of changed entries.
