# Minimum Moves to Balance Circular Array

A circular array `balance` describes people who can transfer exactly one unit to either neighboring person per move. Initially at most one entry is negative. Find the fewest moves needed to make every entry nonnegative, or return `-1` if impossible. `1 ≤ n ≤ 10^5`; each balance lies in `[-10^9,10^9]`. The first and last positions are neighbors.
