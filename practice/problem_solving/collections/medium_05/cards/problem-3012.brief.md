# Minimize Length of Array Using Operations

A nonempty array contains positive integers. An operation selects two distinct positive entries, replaces them with one value equal to the first modulo the second, and shortens the array by one. The replacement can be zero; zeros cannot be selected for later operations. Apply any number of operations to minimize the final array length. Return that length. `1 ≤ nums.length ≤ 10^5`; entries lie in `[1,10^9]`.
