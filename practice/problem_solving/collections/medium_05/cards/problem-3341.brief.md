# Find Minimum Time to Reach Last Room I

A grid of `n×m` rooms has an opening time `moveTime[r][c]` for each room. Start in `(0,0)` at time zero. You may wait in a room; moving to a side-adjacent room takes exactly one second and may start only at or after that destination room’s opening time. Return the earliest arrival time at `(n−1,m−1)`. `2 ≤ n,m ≤ 50`; opening times lie in `[0,10^9]`.
