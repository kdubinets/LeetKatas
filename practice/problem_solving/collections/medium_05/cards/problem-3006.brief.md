# Find Beautiful Indices in the Given Array I

Given lowercase strings `s`, `a`, and `b`, and integer `k`, return all start indices `i` in increasing order such that `a` occurs in `s` starting at `i` and some occurrence of `b` starts at an index `j` with `|i−j|≤k`. Occurrences may overlap, and `i` may equal `j`. `1 ≤ k ≤ |s| ≤ 10^5`; `1 ≤ |a|,|b| ≤ 10`.
