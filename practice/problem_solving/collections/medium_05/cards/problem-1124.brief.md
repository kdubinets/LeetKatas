# Longest Well-Performing Interval

A workday is tiring exactly when its recorded hours are greater than 8. An interval of consecutive days is well performing when it contains strictly more tiring than non-tiring days. Return the greatest length of any such interval, or 0 if none exists. `1 ≤ hours.length ≤ 10^4` and each daily value lies in `[0,16]`.
