# Verify Preorder Serialization of a Binary Tree

A binary tree is serialized in preorder as comma-separated tokens: each non-null node contributes an integer token, and each null child contributes `#`. Given a string of such tokens, decide whether it is the complete serialization of exactly one binary tree. You may not reconstruct the tree. Token spelling and separators are valid; integers range from `0` to `100`, and the string length is at most `10^4`. A lone `#` represents an empty tree.
