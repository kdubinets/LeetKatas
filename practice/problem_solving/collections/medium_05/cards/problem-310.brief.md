# Minimum Height Trees

You are given an undirected tree with `n` vertices labeled `0..n-1` and `n-1` distinct edges. For each possible root, its height is the maximum number of edges from that root to any descendant. Return all root labels that give the minimum height, in any order. The input is guaranteed to be a tree. `1 ≤ n ≤ 2·10^4`; for `n=1` there are no edges.
