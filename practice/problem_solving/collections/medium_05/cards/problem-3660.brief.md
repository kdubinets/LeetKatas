# Jump Game IX

For each index of an integer array `nums`, you may repeatedly jump from index `i` to `j` when either `j>i` and `nums[j]<nums[i]`, or `j<i` and `nums[j]>nums[i]`. Return an array whose entry at `i` is the greatest value at any index reachable from `i`, including its starting index. Equal values alone do not satisfy a jump. `1 ≤ nums.length ≤ 10^5`; values lie in `[1,10^9]`.
