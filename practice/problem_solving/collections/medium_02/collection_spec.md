# Medium Level C 02

This language-neutral medium collection continues the seeded random draw
documented in `../medium_random_selection.json`. Only candidates that pass
the pre-conversion fitness gate enter the collection. Every considered source,
including filtered-out sources, is recorded in that ledger.

The collection holds 25 cards in draw order and is full. Any further reviewed
cards belong in `medium_03` with a new stable collection ID; do not move
existing cards between cohorts.

Each public `.brief.md` contains only the focused problem statement. Its paired
`.card.json` holds the private hint, outline, metadata, and provenance. A
separate clarity reviewer checks each drafted brief before it is treated as
ready for human publication review.
