# Break a Palindrome

You receive a palindrome of lowercase English letters. Replace **exactly
one** character with a lowercase letter so that the result is **not** a
palindrome. Among all valid results, return the lexicographically smallest;
return the empty string if no valid replacement exists.

Lexicographic order compares the first position where two strings differ.
The input length is between 1 and 1,000. For a one-character input, the
answer is the empty string.
