# Count Square Submatrices with All Ones

Given a binary matrix, count **all** square submatrices containing only `1`.
Squares of different sizes or positions count separately; a larger qualifying
square does not replace its smaller qualifying squares.

For an all-ones `2 × 2` matrix, the answer is `5`: four `1 × 1` squares and
one `2 × 2` square. The matrix dimensions are each between 1 and 300.
