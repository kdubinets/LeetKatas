# Binary Subarrays With Sum

Given an array containing only `0` and `1` and an integer `goal`, count its
nonempty **contiguous** subarrays whose sum is exactly `goal`. Subarrays with
different start or end indices count separately, even when their contents are
the same.

For example, five zeros with `goal = 0` have `15` qualifying subarrays.
The array has between 1 and `3 × 10^4` elements, and
`0 ≤ goal ≤ nums.length`.
