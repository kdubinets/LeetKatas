# Longest Subarray With Maximum Bitwise AND

Among all **nonempty contiguous** subarrays of a positive-integer array,
consider the largest bitwise AND value any of them attains. Return the
length of the longest subarray whose AND equals that largest value.

For example, `[1,2,3,3,2,2]` has answer `2`. The array has between 1 and
`10^5` elements, each between 1 and `10^6`.
