# Smallest Subtree with all the Deepest Nodes

In a nonempty binary tree, a node's depth is its distance in edges from the
root. The deepest nodes are those with maximum depth in the entire tree.
Return the **original node** whose subtree contains all deepest nodes and is
smallest among such subtrees. A subtree consists of its root node and all its
descendants.

If there is only one deepest node, return that node. The tree has between 1
and 500 nodes with unique values from `0` through `500`.
