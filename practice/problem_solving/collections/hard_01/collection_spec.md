# Hard Level C 01

This language-neutral Level C collection contains hard problems from the
reviewed foundation collection. It starts with problems 4, 10, and 23,
retaining their prior relative order.

Only hard problems belong here. The collection holds at most 25 cards. Append
new reviewed cards to `problem_order.md`; after reaching 25, create `hard_02`
with a new stable collection ID. Do not move a published card to rebalance
cohorts, since the collection ID is part of its practice identity.

Each public `.brief.md` contains only the focused problem statement. Its paired
`.card.json` holds the hidden hint, outline, metadata, and source provenance.
Validate with `src/scripts/validate_level_c_collection.py` before publication.
