# Coin Change

Given positive coin denominations `coins` and a nonnegative integer `amount`, return the fewest coins needed to sum exactly to `amount`. You have unlimited copies of every denomination. Return `-1` if the amount cannot be formed; amount zero requires zero coins.

`1 <= |coins| <= 12`; `1 <= coins[i] <= 2^31-1`; `0 <= amount <= 10^4`.
