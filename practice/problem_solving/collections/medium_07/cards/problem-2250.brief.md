# Count Number of Rectangles Containing Each Point

Each rectangle is axis-aligned with bottom-left `(0,0)` and top-right `(length,height)`. Given a list of these rectangles and a list of points, return for each point the number of rectangles containing it. Boundaries count as contained. Return counts in point input order.

Each list has `1` to `5 * 10^4` entries. Rectangle lengths and point x-coordinates lie in `[1,10^9]`; rectangle heights and point y-coordinates lie in `[1,100]`. Rectangle coordinate pairs are unique, and point coordinate pairs are unique.
