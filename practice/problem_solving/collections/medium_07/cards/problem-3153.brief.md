# Sum of Digit Differences of All Pairs

Given an array `nums` of positive integers that all have the same number of decimal digits, define the digit difference of two entries as the number of positions where their digits differ. Return the sum of digit differences over all unordered pairs of distinct array indices. Equal-valued entries are still distinct entries.

`2 <= |nums| <= 10^5`; `1 <= nums[i] < 10^9`.
