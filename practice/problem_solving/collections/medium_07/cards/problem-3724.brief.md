# Minimum Operations to Transform Array

Given arrays `nums1` of length `n` and `nums2` of length `n+1`, transform the first exactly into the second. Each operation either increases a chosen element by one, decreases it by one, or appends a copy of a currently chosen element to the end. Operations may affect appended elements too. Return the minimum number of operations.

`1 <= n <= 10^5`; all input values are in `[1,10^5]`.
