# Select K Disjoint Special Substrings

Given a lowercase string `s` and integer `k`, decide whether you can select `k` pairwise disjoint, nonempty contiguous substrings. Each selected substring must be a proper substring of `s`, and every letter occurring inside it must have no occurrence anywhere outside that substring in `s`. Substrings cannot overlap.

`2 <= |s| <= 5 * 10^4`; `0 <= k <= 26`. Selecting zero substrings is allowed.
