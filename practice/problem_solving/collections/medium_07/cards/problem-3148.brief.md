# Maximum Difference Score in a Grid

Given an `m` by `n` grid of positive integers, start at any cell and make at least one move. A move may go to any cell farther down in the same column or farther right in the same row; it need not be adjacent. Moving from value `a` to value `b` earns `b-a`. Return the largest possible total score.

`2 <= m,n <= 1000`; `4 <= mn <= 10^5`; `1 <= grid[i][j] <= 10^5`.
