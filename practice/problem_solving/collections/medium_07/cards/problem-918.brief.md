# Maximum Sum Circular Subarray

Given an integer array `nums` of length `n`, return the largest sum of a nonempty contiguous subarray when the array is circular: the last position is adjacent to the first. A chosen subarray may use each array position at most once.

`1 <= n <= 3 * 10^4`; `-3 * 10^4 <= nums[i] <= 3 * 10^4`.
