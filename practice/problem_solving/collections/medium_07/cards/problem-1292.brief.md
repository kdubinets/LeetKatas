# Maximum Side Length of a Square with Sum Less than or Equal to Threshold

Given a rectangular matrix `mat` with `m` rows and `n` columns and a nonnegative `threshold`, return the largest side length of a square formed by consecutive rows and consecutive columns whose entry sum is at most `threshold`. Return `0` if none exists.

`1 <= m,n <= 300`; `0 <= mat[i][j] <= 10^4`; `0 <= threshold <= 10^5`.
