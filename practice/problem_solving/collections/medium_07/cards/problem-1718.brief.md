# Construct the Lexicographically Largest Valid Sequence

For an integer `n`, return the lexicographically largest sequence containing `1` exactly once and each value `2` through `n` exactly twice. The two occurrences of a value `v >= 2` must have indices differing by exactly `v`. Lexicographic order compares the first position at which two sequences differ. A valid sequence is guaranteed to exist.

`1 <= n <= 20`.
