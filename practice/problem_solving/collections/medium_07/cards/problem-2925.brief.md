# Maximum Score After Applying Operations on a Tree

Given an undirected tree on nodes `0` through `n-1`, rooted at `0`, with positive node values, you may choose a node, add its current value to your score, and set it to zero. Start with score zero. The final tree must have a nonzero sum along every root-to-leaf path. Return the maximum score obtainable; you may perform any number of operations.

`2 <= n <= 2 * 10^4`; the tree has `n-1` edges; `1 <= values[i] <= 10^9`.
