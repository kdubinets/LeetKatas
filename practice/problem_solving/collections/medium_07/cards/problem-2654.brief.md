# Minimum Number of Operations to Make All Array Elements Equal to 1

Given a positive integer array `nums`, one operation chooses two adjacent positions and replaces either one of their values with the GCD of the two current values. Return the fewest operations needed to make every value equal to `1`, or `-1` if impossible. GCD is the greatest common divisor.

`2 <= |nums| <= 50`; `1 <= nums[i] <= 10^6`.
