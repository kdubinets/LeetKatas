# Different Ways to Add Parentheses

An expression contains nonnegative integers from `0` to `99` and the binary operators `+`, `-`, and `*`, with no parentheses. Return a list of the results of **every** full parenthesization; order is arbitrary. Keep repeated numerical results when different parenthesizations produce the same value.

The expression has at most 20 characters. Each result and the total number of returned results fit the source bounds (32-bit values and at most 10,000 results). For `2-1-1`, the answer contains both `0` and `2`.
