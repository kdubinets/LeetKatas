# Find Palindrome With Fixed Length

For each positive integer query `q`, return the `q`th smallest positive decimal palindrome with exactly `intLength` digits, or `−1` if there are fewer than `q` such palindromes. A palindrome reads the same in both directions and cannot start with zero. Query order and duplicates must be preserved.

`1 ≤ queries.length ≤ 50,000`, `1 ≤ q ≤ 10^9`, and `1 ≤ intLength ≤ 15`. For length 3, the first three answers are `101`, `111`, and `121`.
