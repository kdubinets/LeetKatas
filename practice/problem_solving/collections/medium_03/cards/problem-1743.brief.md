# Restore the Array From Adjacent Pairs

An unknown integer array has `n` **unique** elements. You receive its `n−1` adjacent-element pairs, but each pair may be reversed and the pairs arrive in any order. Return any original array consistent with all pairs; its reversal is also acceptable.

`2 ≤ n ≤ 100,000`; values may be negative. A consistent original array is guaranteed to exist.
