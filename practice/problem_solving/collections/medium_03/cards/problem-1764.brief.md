# Form Array by Concatenating Subarrays of Another Array

Given ordered, nonempty integer arrays `groups` and an integer array `nums`, decide whether each group can be matched to a contiguous subarray of `nums`. Matches must appear in group order and share no index; gaps between them are allowed. Equal values in different positions still count as different positions.

There are at most 1,000 groups and at most 1,000 values across all groups. `nums` has at most 1,000 values; values may be negative.
