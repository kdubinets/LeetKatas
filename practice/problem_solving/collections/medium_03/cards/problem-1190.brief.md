# Reverse Substrings Between Each Pair of Parentheses

Given a balanced string of lowercase letters and parentheses, repeatedly reverse the contents of each matching parenthesis pair, starting with the innermost pairs. Remove all parentheses from the final result. Parentheses may be nested or adjacent.

`1 ≤ |s| ≤ 2,000`. For `(u(love)i)`, the result is `iloveu`.
