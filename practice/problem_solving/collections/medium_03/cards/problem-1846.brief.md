# Maximum Element After Decreasing and Rearranging

You may rearrange an array of positive integers arbitrarily and decrease any entries to smaller **positive** integers. Make the resulting array start with `1` and make the absolute difference between adjacent entries at most `1`. Return the largest element value achievable in any valid resulting array.

`1 ≤ n ≤ 100,000`; initial values are at most `10^9`. For `[100,1,1000]`, the answer is `3`.
