# Minimum Number of Flips to Make Binary Grid Palindromic II

You have a binary grid. You may flip individual cells. Find the fewest flips that make **every row and every column** read the same forward and backward, while the final number of ones is divisible by four.

The grid may have one row or one column; `1 ≤ m×n ≤ 200,000`. For example, `[[1],[1]]` needs two flips: leaving two ones is not divisible by four.
