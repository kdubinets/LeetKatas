# Minimize Maximum of Array

You have an array of nonnegative integers. In one operation, choose an index `i > 0` whose value is positive, move one unit from position `i` to `i−1`, and repeat any number of times. What is the smallest possible value of the array’s maximum entry?

`2 ≤ n ≤ 100,000`, and every initial value is at most `10^9`. Units only move left; the total sum does not change.
