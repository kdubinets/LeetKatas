# Number of Longest Increasing Subsequence

For an integer array, count the **index-distinct** subsequences of maximum possible length whose values are strictly increasing. A subsequence keeps original index order but may skip elements. Return the count.

`1 ≤ n ≤ 2,000`; values may be negative or repeated. The answer fits in 32 bits. For `[2,2,2]`, the answer is `3`: each one-element choice is distinct.
