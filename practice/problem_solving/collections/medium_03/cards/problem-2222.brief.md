# Number of Ways to Select Buildings

A binary string describes buildings in street order: `0` means office and `1` restaurant. Count choices of **three increasing indices** whose selected building types alternate, so the selected pattern is `010` or `101`. The chosen buildings need not be adjacent in the street.

`3 ≤ |s| ≤ 100,000`. The answer may exceed 32-bit range. For `010`, there is one valid choice.
