# Mice and Cheese

Each of `n` cheese types must go to exactly one of two mice. Type `i` earns `reward1[i]` for mouse one or `reward2[i]` for mouse two. Mouse one must receive **exactly** `k` types. Return the maximum combined reward.

`1 ≤ n ≤ 100,000`; rewards are positive and at most `1,000`; `0 ≤ k ≤ n`.
