# Medium Level C 03

This language-neutral medium collection continues the seeded random draw
documented in `../medium_random_selection.json`. Candidates pass a
pre-conversion fitness and substantive-similarity gate before inclusion.
Every considered source, including filtered-out sources, is recorded in the
ledger.

The collection holds 25 cards in draw order and is full. Each public `.brief.md`
contains only the focused problem statement. Its paired `.card.json` holds
the private hint, outline, metadata, and provenance. A separate clarity
reviewer checks each draft before it is ready for human publication review.
Further selected cards belong in `medium_04` with its own stable collection ID.
