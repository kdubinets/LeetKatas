# Fruit Into Baskets

An array `fruits` gives the type of fruit at each tree in a row. Choose any
starting tree, then collect one fruit from each consecutive tree while moving
right. You cannot skip a tree, and you have two baskets, each able to hold any
number of fruits of just one type. You may stop at any point.

Return the maximum number of fruits you can collect. The array has between 1
and `10^5` entries, and each type is an integer from `0` through
`fruits.length - 1`.
