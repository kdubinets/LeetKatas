# Top K Frequent Elements

Given an integer array and an integer `k`, return the `k` values that occur
most frequently, in any order. `k` is between 1 and the number of distinct
values, and the requested answer is guaranteed to be unique.

The array has between 1 and `10^5` values, each between `-10^4` and `10^4`.
The running time must be better than O(n log n).
