# Length of Longest Fibonacci Subsequence

Given a strictly increasing array of positive integers, find the maximum
length of a subsequence with at least three elements in which each element
after the first two is the sum of its two predecessors. A subsequence keeps
the input order but may skip elements. Return `0` if no such subsequence
exists.

The array has between 3 and 1,000 elements, with values at most `10^9`.
