# Maximum Good Subarray Sum

Given an integer array `nums` and a positive integer `k`, a nonempty contiguous subarray is good when the absolute difference between its first and last values is exactly `k`. Return the maximum sum of a good subarray, or `0` if none exists. A valid maximum may be negative.

`2 <= nums.length <= 100000`, `-10^9 <= nums[i] <= 10^9`, and `1 <= k <= 10^9`.
