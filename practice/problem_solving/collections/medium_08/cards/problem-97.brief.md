# Interleaving String

Decide whether `s3` can be formed by merging all characters of `s1` and `s2`, preserving each source string's own character order. At each position, the next character may come from either source; both sources must be consumed completely.

`0 <= |s1|,|s2| <= 100`, `0 <= |s3| <= 200`; all characters are lowercase English letters. The follow-up asks for only `O(|s2|)` additional memory.
