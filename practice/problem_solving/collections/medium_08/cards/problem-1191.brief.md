# K-Concatenation Maximum Sum

Repeat integer array `arr` exactly `k` times in order. Return the greatest sum of a contiguous subarray of that repeated sequence, modulo `1000000007`. An empty subarray is allowed and has sum zero.

`1 <= |arr| <= 100000`, `1 <= k <= 100000`, and `-10000 <= arr[i] <= 10000`. The same original position may occur in multiple different copies.
