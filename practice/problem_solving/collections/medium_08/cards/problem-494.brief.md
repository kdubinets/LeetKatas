# Target Sum

Place either a plus or minus sign before **each** indexed value in `nums`. Count the sign assignments whose resulting sum equals `target`. Equal values at different indices still have independent signs; assigning plus or minus to zero counts as two different choices.

`1 <= n <= 20`, `0 <= nums[i] <= 1000`, `sum(nums) <= 1000`, and `-1000 <= target <= 1000`. Return the exact count.
