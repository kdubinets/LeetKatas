# Short Encoding of Words

Encode all strings in `words` using a reference string `s` ending in `#` and one starting index for each input word. Reading from that index until the next `#`, excluding the delimiter, must yield that word exactly. Different words and duplicate occurrences may use overlapping text or the same index. Return the shortest possible length of `s`; you need not return the string or indices.

There are 1 to 2000 words, each of length 1 to 7 and containing only lowercase English letters.
