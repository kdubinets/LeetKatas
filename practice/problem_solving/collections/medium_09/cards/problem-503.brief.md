# Next Greater Element II

Given a circular integer array, return for each element the value of its first strictly greater successor in forward traversal order. Search at most the other `n-1` positions, wrapping from the last position to the first. If no strictly greater value exists, return `-1` for that element. Equal values do not qualify.

`1 <= n <= 10000` and `-10^9 <= nums[i] <= 10^9`. The prescribed `-1` encoding also applies when an actual successor has value `-1`.
