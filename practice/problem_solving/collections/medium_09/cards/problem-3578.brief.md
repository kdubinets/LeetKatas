# Count Partitions With Max-Min Difference at Most K

Partition an integer array into one or more nonempty contiguous segments covering it in order. Every segment must have maximum value minus minimum value at most `k`. Return the number of such partitions modulo `10^9+7`. Different cut positions give different partitions.

`2 <= n <= 50000`, `1 <= nums[i] <= 10^9`, and `0 <= k <= 10^9`.
