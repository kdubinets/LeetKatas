# Shuffle an Array

Maintain an array of distinct integers through two operations. `reset()` returns its original configuration. `shuffle()` returns a permutation in which every permutation of the original elements is equally likely. Calls may be interleaved; a previous shuffle must not change what reset returns or which values later shuffles contain.

`1 <= nums.length <= 50`, `-10^6 <= nums[i] <= 10^6`, and at most `10000` calls to reset and shuffle occur in total.
