# Most Stones Removed with Same Row or Column

On an integer-coordinate plane, each occupied point holds one stone. You may remove a stone only if another stone still present shares its row or its column. Return the maximum number of stones that can be removed by a sequence of legal removals. Sharing a row or column does not require neighboring coordinates.

`1 <= stones.length <= 1000`, `0 <= x_i, y_i <= 10000`, and all occupied points are distinct.
