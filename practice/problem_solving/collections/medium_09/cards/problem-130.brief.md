# Surrounded Regions

Given a rectangular board of `X` and `O`, connect O cells that share a horizontal or vertical side. Replace every O belonging to a connected region with no cell on the outer edge by X. Preserve all O regions that touch an edge and all existing X cells. Modify the board in place; no separate result is required. Diagonal contact does not connect cells.

Both dimensions are between `1` and `200`. For example, on a single-row board every O is on the edge, so none is captured.
