# Delete Node in a Linked List

You are given a node in a singly linked list, but not the list's head. Delete
the given node in place: its value must disappear, the list must have one fewer
node, and the values before and after it must retain their order. Values are
unique, and the given node is guaranteed to be in the list and not its tail.

The list has between 2 and 1000 nodes, with values between `-1000` and `1000`.
