# Merge k Sorted Lists

Given an array of `k` singly linked lists, each sorted in nondecreasing order,
merge all their nodes into one sorted linked list and return its head.

There may be no lists, and individual lists may be empty. `0 <= k <= 10^4`,
each list contains at most 500 nodes, the total number of nodes is at most
`10^4`, and node values lie between `-10^4` and `10^4`.
