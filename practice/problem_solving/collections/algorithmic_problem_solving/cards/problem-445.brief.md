# Add Two Numbers II

Two non-empty linked lists represent non-negative integers in forward digit
order: each node holds one digit and the most significant digit comes first.
Return their sum in the same linked-list format. Neither input has leading
zeros unless it represents zero.

Each list has between 1 and 100 nodes, and each node value is between 0 and 9.
Consider also whether this can be done without reversing either input list.
