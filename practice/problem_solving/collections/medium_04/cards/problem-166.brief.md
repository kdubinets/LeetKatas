# Fraction to Recurring Decimal

Given signed 32-bit integers `numerator` and nonzero `denominator`, return their exact decimal representation as a string. If the fractional digits eventually repeat, put parentheses around the **repeating portion**; if they terminate, use a finite decimal without parentheses. Negative answers start with `-`. The generated answer has fewer than 10,000 characters.

For `4/333`, the result is `0.(012)`; for `1/2`, it is `0.5`.
