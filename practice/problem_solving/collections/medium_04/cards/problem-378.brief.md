# Kth Smallest Element in a Sorted Matrix

An `n × n` integer matrix has every row and every column sorted in **nondecreasing** order. Return the kth smallest entry when all `n²` entries are listed with duplicates included; k is 1-based. Use less than O(n²) auxiliary memory. `n` is at most 300, and entries range from -10^9 to 10^9.

For `[[1,5,9],[10,11,13],[12,13,15]]`, k=8 returns 13; both copies of 13 count separately.
