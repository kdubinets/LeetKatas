# Insert Delete GetRandom O(1)

Design a set of integers with three operations: `insert(v)` returns whether `v` was newly added; `remove(v)` returns whether it was present; `getRandom()` returns one current value with **equal probability for every value**. The set is guaranteed nonempty when `getRandom()` is called. Each operation must take average O(1) time. Values fit signed 32-bit integers, and there are at most 200,000 calls.
