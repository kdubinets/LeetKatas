# Maximum Number of Events That Can Be Attended

Each event has an inclusive start and end day. You may attend it on any one day in that interval, with at most one event attended per day. Given up to 100,000 events whose day values are between 1 and 100,000, return the largest number of events you can attend. Events may share intervals and each event can be attended at most once.

For example, intervals `[1,2]`, `[2,3]`, and `[3,4]` allow all three events to be attended on days 1, 2, and 3.
