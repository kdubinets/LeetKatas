# Minimum Number of Coins to be Added

You have an array of positive coin values. A positive sum is obtainable if it equals the sum of a nonempty selection of existing coin occurrences; each occurrence can be used at most once. You may add coins of **any positive integer value**. Return the fewest additions needed so every integer from 1 through `target` is obtainable. The array and target are each at most 100,000, and every original coin is at most `target`.

For coins `[1,4,10]` and target 19, adding values 2 and 8 suffices, so the answer is 2.
