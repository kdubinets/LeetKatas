# Minimize the Difference Between Target and Chosen Elements

Given a matrix of positive integers and a target, choose **exactly one** entry from each row. Return the smallest absolute difference between the sum of chosen entries and the target. The matrix has at most 70 rows and 70 columns; each entry is 1–70 and the target is 1–800. Repeated values in a row are allowed.

For rows `[1,2,3]`, `[4,5,6]`, `[7,8,9]` and target 13, choosing 1, 5, and 7 gives difference 0.
