# Minimum Number of Work Sessions to Finish the Tasks

Finish every task in array `tasks` using as few work sessions as possible. A session lasts at most `sessionTime` hours; a task cannot be split across sessions. Tasks may be done in any order and a new task can start immediately after the previous one. Return the minimum session count.

`1 <= |tasks| <= 14`; `1 <= tasks[i] <= 10`; `max(tasks) <= sessionTime <= 15`. Equal-duration tasks are still distinct tasks.
