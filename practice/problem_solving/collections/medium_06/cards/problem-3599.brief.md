# Partition Array to Minimize XOR

Partition integer array `nums` into **exactly** `k` nonempty contiguous subarrays. The score of each part is the bitwise XOR of its elements. Minimize the largest part score and return that minimum.

`1 <= |nums| <= 250`; `1 <= nums[i] <= 1000000000`; `1 <= k <= |nums|`.
