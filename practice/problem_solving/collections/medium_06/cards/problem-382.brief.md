# Linked List Random Node

Implement a class initialized with the head of a nonempty singly linked list. Each call to `getRandom()` must return a node’s value, with **every node** having equal probability of selection on each call. Equal values at different nodes remain separate outcomes.

The list has `1` to `10000` nodes, with values in `[-10000,10000]`; at most `10000` calls occur. Follow-up: handle an extremely large list whose length is not known in advance, using no extra space proportional to its length.
