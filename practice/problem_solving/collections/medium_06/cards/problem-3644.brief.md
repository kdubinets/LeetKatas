# Maximum K to Sort a Permutation

`nums` is a permutation of `0` through `n-1`. Fix a nonnegative integer `k`; you may swap two elements only when the bitwise AND of their **values at the time of the swap** equals `k`. Return the largest `k` for which some sequence of such swaps sorts the array. If already sorted, return `0`.

`1 <= n <= 100000`.
