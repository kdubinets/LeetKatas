# Maximum Number of Occurrences of a Substring

Given a lowercase string `s`, find the greatest number of occurrences of any substring whose length is between `minSize` and `maxSize`, inclusive, and which contains at most `maxLetters` distinct letters. Count overlapping occurrences separately. Return `0` if no substring qualifies.

`1 <= |s| <= 100000`; `1 <= maxLetters <= 26`; `1 <= minSize <= maxSize <= min(26, |s|)`.
