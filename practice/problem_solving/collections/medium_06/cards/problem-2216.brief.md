# Minimum Deletions to Make Array Beautiful

Delete as few elements as possible from an integer array `nums` so the remaining array has even length and, at every even index `i`, its elements at `i` and `i + 1` differ. Deletion preserves the order of the remaining elements; the empty array is valid. Return the minimum deletion count.

`1 <= |nums| <= 100000`; `0 <= nums[i] <= 100000`. The index condition applies to the **remaining** array.
