# Validate Binary Tree Nodes

Nodes `0` through `n-1` each name a left and right child through arrays `leftChild` and `rightChild`; `-1` means no child. Determine whether **all** the nodes form exactly one valid binary tree. Child links are directed from parent to child, and node numbers are identities rather than values.

`1 <= n <= 10000`; both arrays have length `n` and entries in `[-1, n-1]`.
