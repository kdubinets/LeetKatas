# Maximum Number of Groups Entering a Competition

Partition **all** students, represented by positive integer `grades`, into the largest possible number of ordered nonempty groups. For each consecutive pair of groups, both the group size and the sum of grades must strictly increase. Students may be assigned in any order. Return only the maximum group count.

`1 <= |grades| <= 100000`; `1 <= grades[i] <= 100000`. Equal grades are allowed.
